# CLAUDE.md / dev-rules への改善提案(dcd8234d、仕様還流後の再実行)

既存の CLAUDE.md と dev-rules は変更していない。採否は人が判断する。

## 提案 1: 仕様の変更要求には、要求本文と受け入れ基準の追随を完了条件に含める

- 対象: relay-gate の CLAUDE.md「開発プロセス」の還流に関する記述
- 理由: 仕様だけを更新した還流で、要求 SPEC-004-04 の「検証は 2 点だけ」が残り、受け入れテストと仕様のテストが矛盾した
- 案: 「仕様に規則を足す・変える変更要求は、関係する要求の本文・受け入れ基準・UC の API 要約が同じ内容になることを完了条件に書く」を加える

## 提案 2: env 形式の設定ファイルの読み込み規則を 1 か所にまとめる

- 対象: CLI 契約の共有規則(`config_input_rules.env_files` と `shared_rules.compare_command_argv`)
- 理由: 実装者が補った前提のうち 5 件(重複キー、前後空白、空キー、引用符の除去、未知キーの扱い)は、どの env ファイルにも共通する読み込み規則で、feature flag 設定の既存実装に揃えて補った。引用符の除去は 2 か所の書き方が揃っておらず一意に読めない
- 案: env ファイルの読み込み規則(重複キー・空白・空キー・引用符・未知キー)を共有規則として 1 か所に定め、各設定ファイルはそれを参照する。決めるかどうかはレビューで判断する(現時点では仕様変更要求にしていない)
