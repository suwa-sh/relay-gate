# 実行境界レビュー skill への提案

## 何が起きたか

実装レビューで、timeout、remote handshake、共有ファイル、RDB、監査の契約不足が複数 attempt にわたり個別に見つかった。

## 原因

外部境界をまたぐ UC に対して、仕様の入力・出力・識別子・状態・timeout・補償・監査を一括で確認する定型チェックがなかった。

## 回避方法

実装レビュー skill に、remote/RDB/file/CLI の境界ごとに、契約所有者、相関 ID、timeout 後状態、冪等性、補償、監査 sink を確認するチェックリストを追加する。

## 次回の対応

skill 所有者は、このチェックリストを S4 前の仕様読込と S5 の verifier 観点へ提案し、外部境界を持つ UC で試行する。
