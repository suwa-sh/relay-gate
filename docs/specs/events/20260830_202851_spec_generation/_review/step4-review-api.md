## 総評

- CLI コマンド契約は 32 UC の `_api-summary.yaml` に現れる全 15 コマンド(facade.sh / $BLUE_RUNNER・$GREEN_RUNNER / rapid-crosscheck-runner.sh / rapid-crosscheck-worker.sh / rapid-crosscheck-result.sh / final-crosscheck-runner.sh / final-crosscheck-worker.sh / hang-detector.sh / hang-detect-trend.sh / background-rerun.sh / abort-blue.sh / abort-green.sh / abort-rapid-crosscheck.sh / abort-final-crosscheck.sh / run-lineage.sh / validate-config.sh)を網羅している。各コマンドに args / options / stdin / stdout / stderr / exit_codes / idempotency が具体値で記載されている
- 終了コード体系は `_inference.md` 採用値 #2(0 / 2 / 3 / 6、中継系は保存済み exitcode をそのまま、1 は不使用)と一致
- コマンド名・オプション名は全て kebab-case。tier md の `書式` 行(全 30 パターン)と contract の synopsis を突き合わせ、コマンド / オプション名の食い違いなし
- asyncapi.yaml は全 UC の `async_events`(4 チャネル: slot-completed / rapid-crosscheck-requests / final-crosscheck-requests / hang-alert-mail、メッセージ名 SlotCompletedNotice / RapidCrosscheckRequestMessage / FinalCrosscheckRequestMessage / HangAlertMail)を網羅。schemas は全て title・description あり、enum に値あり、$ref は全て解決済み、無名スキーマなし
- 状態 enum(parallel_runs.status / slot_executions.status / request status / rapid_runs.completion_status / comparison_results.status / monitor_records.monitor_status / role)およびテーブル名(parallel_runs / slot_executions / rapid_runs / rapid_crosscheck_requests / comparison_results / final_crosscheck_requests / monitor_records)は `rdb-schema.yaml` と一致
