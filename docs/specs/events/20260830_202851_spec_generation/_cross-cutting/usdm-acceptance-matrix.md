# USDM 受け入れ条件 × UC Spec 対応表(Step6.5 観点①)

## 前提(これだけ知っていれば読める)

- USDM の正本は `docs/usdm/latest/requirements.yaml`(REQ 13 件 / SPEC 44 件。各 SPEC に Given/When/Then の受け入れ条件が 1〜3 件)
- UC Spec 側の対応づけは、各 UC の `spec.md`「関連 USDM」表(REQ ID / SPEC ID / 対応 BDD Scenario)から機械的に集計した。シナリオ名末尾の `(SPEC-xxx)` は除いて表記する
- UC ID(UC-01〜UC-32)は `uc-dependencies.md` / `_inference.md` と同じ番号
- 状態の定義: **covered** = 全受け入れ条件に対応する BDD シナリオが少なくとも 1 つの UC にある / **partial** = 受け入れ条件の一部だけに対応、または SPEC 本文の要素が UC Spec 側と食い違う / **uncovered** = 対応 UC が無い
- 本ファイルは第 3 ラウンド(Step6.5 反証レビュー round-1 の修正: `_review/round-1-resolution-G1〜G4.md` / `round-1-consolidation.md`。BDD シナリオ名・Given の修正、UC「リラン対象を検証する」/「確報クロスチェック結果を確認する」の関連 USDM 追加 等)後の全 32 UC の spec.md「関連 USDM」表と `requirements.yaml`(変更なし: REQ 13 / SPEC 44)を突き合わせて再集計した
