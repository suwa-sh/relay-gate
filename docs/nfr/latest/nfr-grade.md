| 確信度 | 意味 |
|:------:|------|

| 中 | RDRA モデルから間接推論 |
| 低 | 弱い根拠での推論 |
| デフォルト | モデルシステムのデフォルト値 |
| ユーザー指定 | 対話でユーザーが指定 |
