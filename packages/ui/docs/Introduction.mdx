# RelayGate Ops デザインシステム

RelayGate は Web UI を持たない CLI / バッチ運用中心の実行基盤です。アーキテクチャ設計上、
presentation 層は「ジョブスケジューラからの入力解析」と「標準出力・標準エラー・終了コードのみへの
整形出力」に限定されており、Web フロントエンドティアは存在しません（`docs/arch/latest/arch-design.yaml`）。

このデザインシステムは、運用者が実際に接する **CLI 出力・対話確認・通知メールの表示規約** と、
将来の運用ダッシュボード構築に備えた **最小限のデザイントークン** を対象とします。
RDRA モデルに存在しない Web 画面は発明せず、BUC.tsv の「画面」列（23件）を
CLI 上のインタラクションのタッチポイントとして再解釈しています。
