# Contributing

Thank you for your interest in RelayGate!

## Current phase

The project is in the specification phase — the runtime is not implemented yet. The specification set under `docs/` is the source of truth (see `CLAUDE.md` for the spec-driven workflow).

## How to participate

- **Questions / bug reports / proposals**: open an [Issue](https://github.com/suwa-sh/relay-gate/issues). Japanese or English are both welcome.
- **Pull requests**: welcome for documentation fixes. For behavior or specification changes, please open an Issue first so we can align on the spec (`docs/specs/latest/`) before code.
- Specification changes must go through the distillery pipeline (see `CLAUDE.md`), not direct edits to `docs/*/latest/`.
